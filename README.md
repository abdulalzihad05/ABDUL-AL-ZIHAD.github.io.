# Abdul Al Zihad — Academic & Research Portfolio

A responsive academic portfolio built with HTML, CSS, and vanilla JavaScript. No build tools are required.

## Website sections
- Academic introduction and research profile
- Research interests
- Current AI-based solar energy forecasting project
- Publications section (ready for verified entries)
- CV download section
- Contact and professional links

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then save.
4. Wait for the deployment workflow to complete.

## Personalise before sharing
- Replace `YOUR.EMAIL@example.com` in `index.html` with the professional email address you want public.
- Replace the generic LinkedIn and GitHub profile links with your own profile URLs.
- Upload your latest CV as `assets/Abdul_Al_Zihad_CV.pdf`.
- Add only verified publications, completed projects, results, and credentials.

## Research accuracy
The featured solar forecasting project is labelled **Research in progress**. No experimental results or publications are claimed. Add metrics such as MAE, RMSE, and MAPE only after validating the results.

## Local preview
Open `index.html` in a browser, or run `python -m http.server 8000` in this directory and visit `http://localhost:8000`.
